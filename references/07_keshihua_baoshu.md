# 可视化命书 · 一页 HTML 报告产出规范

> 先完成当前主题所需的计算与有依据的解释，再用 HTML 把结论**呈现**得更易读、易藏、易分享。完整命书走 SKILL 第 0 至 10 步，单维度保留必要基础并聚焦该主题；HTML 正文与对应文字版逐字一致，绝不为排版另造结论。

## 一、何时做 · 默认交付

- 当前主题所需推演完成后，**直接产出一页可视化 HTML 命书**，作为默认交付的一部分，不再征询「要不要」。仅当用户明确说只要文字版时跳过；用户开头就点名要 HTML 的，视为已授权。
- 默认口径无需确认：主题默认「我的一生」（用户只问单一维度时换成对应主题）；信息按用户提供的原样呈现。仅当用户提到对外分享、发布或入库时，才提醒脱敏（见第七节）。
- **输出与交付**：写入当前工作目录（用户指定目录则从之），文件名 `命书-<姓名或代号>-<公历生日YYYYMMDD>.html`；交付时给完整绝对路径，并在支持的环境下用系统命令直接打开（macOS `open` / Linux `xdg-open` / Windows `start`），打不开就给路径请用户点开。
- 未完成当前主题的必要计算与解释时，不直接出 HTML。只求排盘、JSON 或明确纯文字的任务服从用户范围；不为生成 HTML 强制展开全维度推演。

## 二、设计定位

- 一页到底的「命书」长卷：东方雅致、有命理质感，像一本可收藏的个人之书。
- 一屏一主角：每屏只讲一件事（一个命盘、一组五行、一条主轴结论），不堆砌。
- 签名时刻：全局设计一个最大记忆点，把命局命门（最关键的用神、缺神或格局字）单字放大成全屏主视觉。

## 三、字体可靠性铁律（最重要，踩过坑）

中文命书最容易翻车在字体，规则按优先级：

1. **思源宋体为骨架，系统宋体兜底**：正文与标题统一字体栈 `'Noto Serif SC','Songti SC','STSong','Songti TC',serif`。webfont（Noto Serif SC）联网时加载，断网或加载失败时无缝退到系统宋体，断网也不塌字、绝不掉成 Times。
2. **层次靠字重，不靠书法字体**：大标题与签名字 `font-weight:900`、命盘单字 700、雅致小标 400–600、正文 300。Google Fonts 的 `<link>` 记得把 `900` 加进 `wght@…;900`。
3. **不赌本地书法体**：魏碑、行楷、楷体（Weibei SC / Xingkai SC / Kaiti SC）在 macOS 多是「按需下载」字体，未必预装，写进字体栈会塌成默认衬线。想要书法效果只能内嵌子集化字体文件，否则一律用宋体加字重方案。
4. **拉丁数字与年份**：用一款衬线（如 Cormorant Garamond），兜底 Georgia，与中文宋体协调。
5. **大标题防孤字**：`white-space:nowrap` + `clamp()` 控字号 + `text-wrap:balance`；中文宽度不要用 `ch` 单位。

> 验收：断网打开页面，中文应仍是工整宋体，若塌成 Times 衬线即字体栈失效；标题字重层次分明。

## 四、性能与反 AI 体检（出货铁律）

- 不动画 `text-shadow` 与 `box-shadow`；不用 `backdrop-filter`；不给带模糊的元素做动画。
- 无限动画只动 `transform` 和 `opacity`；不留常驻 `requestAnimationFrame`。
- 所有动效能被 `@media (prefers-reduced-motion:reduce)` 一键关停。
- 默认输出纯静态命书，正文始终可见；阅读目录使用原生锚点。只有用户明确要求滚动揭示时才引入 IntersectionObserver，并保证禁用 JS、打印及减少动态效果时内容仍完整可见。
- 反 AI 套路：拒绝紫色渐变白底、全文套用无差别的西文字体、居中堆叠的模板感。用纸墨配色加一个朱砂、一个金，疏密与留白要有节奏。

## 五之一、黑哥解读区块（每个内容区块必配，铁律）

命书面向普通人，专业术语（伤官、比劫、调候、值符、飞化…）不解释就是天书。**每个内容区块（卷）末尾必须带一个「黑哥解读」框**，把该段的专业内容翻译成普通人能看懂的话：

- **只翻译，不新增结论**：黑哥解读是同一结论的白话版，严禁借翻译夹带正文没有的新断语。
- **术语逐个拆**：该段出现的每个关键术语都要给人话（如「伤官生财＝你的才华能直接变成钱」「缺水＝这个命的油门太多、刹车没有」）。比喻降维到给我妈能解释清楚的程度，贴日常生活（工作、开车、做饭、存钱），不用玄学词解释玄学词。
- **口吻**：短句、口语、用「你」，像懂行的朋友当面给你讲盘，两到五句讲完，别写成第二篇论文。
- **视觉**：独立卡片样式，与正文区分（左侧朱砂竖线 + 「黑哥解读」印章式小标签，底色比正文卡略深或略浅一档），全卷统一、一眼可辨；打印态保持可读。
- **覆盖面**：命盘、五行、旺衰、用神、格局、大运流年、分维度各段、紫微互参等全部内容卷逐卷配一个；纯装饰区（卷首、签名时刻、页脚）不配。
- 写作红线与全库一致：全角标点、无破折号、无否定对比句式、不恐吓不承诺。

## 六、配色取命局

- **主色调取用神五行**：木青绿 · 火朱红 · 土土黄 · 金月白 · 水墨蓝。用神色做全局基调。
- **底色**：墨黑或宣纸暖白二选一，深色更显命理质感。
- **签名色**：一个朱砂（印章、书脊、强调）加一个金（标题、分隔线、边框）。
- **忌神色仅作点缀**：例如火为忌，火红只用在「软肋 / 警示」处，不铺满。
- 一份报告的色彩控制在「底色 + 用神主色 + 朱砂 + 金 + 一个辅助色」之内，不堆色。

## 七、脱敏与合规

- 对外分享或入库（如做成 skill 示例）：八字加生辰本身就是强身份标识，**只改姓名远远不够**。要脱敏就换一个虚构生辰、重新排盘，断语写通用教学向，不写可对号入座的具体生活事件。
- 页脚固定声明：本报告是传统文化研究与自我认知参考，非预言或保证，不承诺改运消灾。
- 全篇措辞趋势化（易 / 倾向 / 利于 / 需注意），不恐吓、不承诺祸福，与文字版同一口径。

## 八、长命书的阅读与保存

- 卷首提供「直接看命盘」和「选择章节」两个原生链接。目录使用普通人的目标作为名称，例如命盘、用神、大运、具体建议；目录文字只概括已有章节，不新增断语。
- 为主要章节设置唯一的 `id` 和真实 `h2` 标题。目录、返回卷首均用原生锚点，离线及关闭 JavaScript 时仍可阅读。长报告可使用窄条阅读导航，但不能挡住锚点标题或手机正文。
- 标题字号按可用宽度缩放，不能只设置很大的最小字号再强制不换行。依据标签允许换行，不能使用横向隐藏来掩盖裁切。验收至少覆盖 320、390 和 1440 像素视口，并检查元素边界。
- 交互入口至少有 44 像素触控高度，键盘焦点清晰。装饰字符对辅助技术隐藏。微交互只用于反馈，低动态偏好下关闭过渡，正文始终直接可见。
- 打印时隐藏阅读工具和装饰，保持白底黑字；表格行、白话框尽量不跨页截断。用浏览器打印功能保存 PDF，无需假设用户知道终端操作。
- 示例的新阅读组件采用 HeiGe-Design 的 `noir-vermilion` 设定：玄黑 `#141210`、奶白 `#EDEAE3`、绛红 `#CE1432`，手稿目录卡配大序号。此范围仅为阅读组件；命局五行语义配色和原有命书正文保持一致。设定集采用 MIT 许可。
- 姓名、问题和正文作为文本插入 HTML 时必须转义，文件名只保留安全的普通字符。不要把用户原文插入脚本、HTML 属性或系统命令。

打开本仓库示例并检查目录、跳转与打印后，再交付新的命书。规范检查通过后仍需实际浏览器验收。

## 九、固定末尾功能提示

所有主题均按 `references/23_report_next_steps.md`，在正文及附录之后、原有页脚声明之前放置完整功能目录。目录为产品使用说明，不属于命理解读，不增加「黑哥解读」框。沿用当前报告样式，默认展开，纯文字与 HTML 提供相同的功能和示例说法，打印时保留。用户选择后才开展相应分析；已有资料不重复索取。
