# 报告末尾 · 功能与使用提示

## 放置规则

- 八字、合参、紫微、梅花、六爻、奇门的完整报告、单主题报告和纯文字解读，统一在正文及附录之后、原有参考声明之前附上以下提示，一份报告只出现一次。
- 标题、开场、九项功能和收尾组成完整提示。每项保留用途、示例说法、所需信息；示例中的年份和问题可按上下文替换。各引擎的实际能力范围以对应方法文档为准。
- 这是一份固定功能目录，区别于按相关性筛选的主动建议，不受两三项推荐上限影响，也不增加命理解读或「黑哥解读」框。
- HTML 默认展开可读，使用当前报告已有样式，手机端自然换行，打印时保留。示例说法使用可选择的普通文本，提示用户发回对话；没有真实执行能力时不要做成运行按钮。
- 用户只要求脚本原始输出、JSON、核对数据，或明确不要功能提示时省略；不向机器可读结果追加文字。用户说不用继续时不再追加追问或重发目录。
- 仅交付文件链接的聊天回复，提醒「报告末尾列有其他功能和示例说法」即可，不在聊天里再复制整份目录；若聊天本身交付完整文字解读，则在文字末尾保留提示。

## 标准提示内容

### 这份报告之后，你还可以做什么

HeiGe-SuanMing 还可以继续做下面这些分析。挑一项，把示例说法发回当前对话即可；已经提供过的资料会沿用，只补充新问题需要的信息。

- **八字完整命书**：从性格、事业、财富、感情到人生阶段，做一次整体解读。
  可以这样说：「按八字给我做一份完整命书。」
  需要提供：出生年月日、公历或农历、性别；已知时分、出生地和时区一并提供。

- **单个主题深入看**：把事业、赚钱方式、感情或家庭单独展开。
  可以这样说：「只看我的事业，把工作方式和合作问题讲具体。」
  需要提供：说清想深入的主题；已有出生资料可继续使用。

- **指定年份与月份**：集中看某一年，或细看这一年各个月份的阶段变化。
  可以这样说：「看看我2027年的事业，细到月份。」
  需要提供：指定年份和关注主题；已有出生资料可继续使用。

- **两个人的关系**：比较双方的相处方式、容易合拍的地方与需要磨合的分歧。
  可以这样说：「帮我分析和伴侣的相处方式。」
  需要提供：补充另一人的出生资料，不知道的时辰明确写未知。

- **紫微斗数**：从事业、财富、伴侣、家庭等十二类生活领域看命盘，目前提供排盘和基础框架解读。
  可以这样说：「用紫微给我排盘，看看各个生活领域。」
  需要提供：出生资料中需要有出生时辰；已有资料可继续使用。

- **梅花易数**：用两个数字或指定时间，围绕一件事看当前状态与后续变化。
  可以这样说：「用梅花看未来一个月的求职进展，数字34、43。」
  需要提供：具体问题、关注期限，以及两个正整数或起卦时间。

- **六爻**：围绕一件事，分别看自己、对方、关键阻碍和变化条件。
  可以这样说：「我想用六爻问这次合作，先告诉我怎么记录六次摇卦。」
  需要提供：具体问题、关注期限、起卦日期时间和六次摇卦结果。

- **奇门遁甲**：针对某个时刻，观察一件事的整体局面、机会和阻力。
  可以这样说：「用奇门看这次合作洽谈的局面。」
  需要提供：具体问题、关注期限和起局年月日时分，注明时间口径。

- **日常配色与生活建议**：把报告里的建议展开成衣着、配饰、环境配色和日常作息清单。
  可以这样说：「把我的穿衣配色和日常作息建议单独列出来。」
  需要提供：说清想要穿搭、环境还是作息建议，也可补充现有习惯。

报告也可以只要文字版；HTML 命书可通过浏览器打印保存为 PDF。选好后，把对应说法发回对话即可。
