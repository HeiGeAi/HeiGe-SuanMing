# 手机号八星结构分析

## 定位

手机号八星是独立的数字结构分析引擎。它回答“号码由哪些相邻数字组合构成、这些组合在指定规则版本中对应什么星”，不替代八字命盘，也不把八星结果、八字五行和其他占测结果自动合并成一个命运分。

当前版本：`eight_star_v1`。计算引擎：`scripts/phone_energy.py` v0.2.0。

## 输入契约

```bash
python3 scripts/phone_energy.py 13812345678
python3 scripts/phone_energy.py 138-123-45678 --json --pretty
python3 scripts/phone_energy.py 13812345678 --exclude-leading-one --json
python3 scripts/phone_energy.py 13812345678 --html output/手机号八星报告.html
```

- 输入可包含空格、短横线、括号等格式字符，脚本只保留数字。
- 支持 `mobile`、`plate`、`address`、`general` 四种号码类型。
- 默认保留完整输入。只有明确传入 `--exclude-leading-one` 且号码类型为 `mobile` 时，才排除固定首位 `1`。
- 结构化结果中的手机号使用脱敏值。相邻数字对本身属于分析依据，会按组输出。
- 不含数字、未知号码类型或未知规则版本时，脚本以非零状态退出。
- `--html [PATH]` 生成沿用项目命书视觉系统的单页 HTML 报告；不指定路径时写入当前目录的脱敏文件名。报告除了结构统计，还会按 `references/phone_energy_readings_v1.json` 给出主导星白话解读、生活场景、自查问题、沟通句式、七天行动练习和完成标准。

## 计算顺序

1. 清洗输入并记录号码类型、长度和规则版本。
2. 生成相邻两位的重叠组合。长度为 n 的数字串得到 n−1 组。
3. 按 `references/phone_energy_rules_v1.json` 查询八星、吉凶类型、领域和 L1 至 L4 能量等级。
4. 保留无法独立成星的相邻组合，标记为“未分类”，不能静默删除。
5. 检测 `0` 与 `5`。它们不独立成星：夹在有效数字之间时分别标记为 `hidden` 或 `amplified`；位于首尾时标记为 `edge_fu_wei`。
6. 统计八星数量、吉星/伏位/凶星数量、主导星、最后一个有效星组和修饰记录。
7. 输出 JSON 或人类可读的 CLI 结果。

用户明确要求报告时，使用 `--html` 生成 HTML。报告沿用项目命书的玄黑、奶白、绛红和金色 token，阅读顺序是“计算结果 → 白话结论 → 生活场景 → 自查问题 → 行动步骤 → 规则依据”。报告包含卷首、结构统计、主导星解读、相邻数字对、八星分布、0/5 修饰、七天行动计划、规则边界、黑哥解读和打印态；页面不写入原始完整号码，也不包含脚本。解释文案版本独立记录为 `eight_star_reading_v1`，方便后续修订表达而不改变数字计算规则。

## 结果边界

结果属于固定数字规则下的文化研究和自我观察参考。它不构成医疗、法律、投资或人生决策建议。健康、财富、婚姻、事故等后续解释必须使用倾向性表达，并绑定具体数字对和规则版本。

八星与八字交叉时，先独立运行 `phone_energy.py`，再按用户主动提供的出生信息运行 `scripts/paipan.py`。报告保留“号码结构层”和“八字交叉层”两个独立层，不生成没有依据的混合命运分。
